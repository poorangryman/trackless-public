## 📦 Регламент обработки пачки
1. Накопление пунктов в секции выше.
2. Команда пользователя: *"примени очередь"* / *"делай батч"*.
3. Агент реализует все пункты за один проход.
4. Сборка, единый бамп версии в `VERSION.txt`, коммит, тег и пуш.
5. Очищенные задачи переносятся в историю ниже.

## 📜 Архив выполненных пакетов

### v1.6.10 (2026-09-26)
- [x] **Редизайн виджетов (Small & Wide):** Цветовая палитра обновлена под новую бежевую тему (BgCard, PrimaryAccent). Кнопка '+' теперь использует бежевый градиент и чёрную иконку.
- [x] **Таймеры в виджетах:** Исправлено переполнение текста `Chronometer`. Установлены ограничения `autoSizeTextType="uniform"` и `fillMaxWidth()` для корректного скейлинга таймера, чтобы он не вылезал за границы при больших значениях.


### v1.6.9 (2026-09-26) - Hotfix
- [x] **Экспорт/Импорт:** Исправлено отсутствие реакции на кнопки. Теперь `LocalContext` корректно разворачивается (unwrap `ContextWrapper`) до `MainActivity`, что позволяет вызвать системные диалоги сохранения файлов.


### v1.6.8 (2026-09-26)
- [x] **Бесконечный цикл в ViewModel:** Убран `while(true) { delay(1000) }` для обновления времени в `TracklessViewModel`. Реализовано через `WhileSubscribed(5000)`.
- [x] **Лишняя рекомпозиция `MainScreen`:** Стейт времени передаётся как `StateFlow` в карточки `HeroCard` и `StatsGrid`, что спасает фон и сам экран от лишних перерисовок.
- [x] **Иконка приложения:** Масштаб вектора `ic_trackless_foreground` уменьшен под safe zone, применены цвета бежевой темы.
- [x] **Зоны нажатия:** Увеличена площадь клика до гайдлайнов `48.dp` для `IconButton` в истории.
- [x] **Цвета и легаси API:** Старые цвета (Cyan, Amber) заменены на `PrimaryAccent`, устранен Deprecation Warning для `LinearProgressIndicator`.

### v1.6.7 (2026-09-22)
- [x] Редизайн цветовой палитры: убран зелёный, внедрены чёрный (`#000000`), тёмно-серый (`#141414`), молочно-белый (`#F5F5F5`) и бежевый (`#E5D5C5`).
- [x] Удаление верхней кнопки Undo (удаление доступно только через историю).
